Feature: Cuisine Color Theme Switcher
  As a Deld user
  I want to personalize the app with cuisine-inspired color themes
  So that my browsing experience matches my culinary preferences

  Background:
    Given the app is running at "http://localhost:3000"

  @unit-test @priority-high
  Scenario: Theme switcher dropdown displays all three cuisine theme options
    Given I am on the home page
    And the page has fully loaded
    When I click the theme switcher trigger button with data-testid "theme-switcher-trigger"
    Then the theme menu with data-testid "theme-switcher-menu" should be visible
    And I should see exactly 3 theme options in the dropdown
    And I should see the Italian theme option with data-testid "theme-option-italian"
    And I should see the Japanese theme option with data-testid "theme-option-japanese"
    And I should see the Mexican theme option with data-testid "theme-option-mexican"

  @unit-test @priority-high
  Scenario: Selecting Italian theme updates body data-theme attribute
    Given I am on the home page
    And the page has fully loaded
    When I click the theme switcher trigger button with data-testid "theme-switcher-trigger"
    And I click the Italian theme option with data-testid "theme-option-italian"
    Then the body element should have attribute data-theme equal to "italian"

  @unit-test @priority-high
  Scenario: Selecting Japanese theme updates body data-theme attribute
    Given I am on the home page
    And the page has fully loaded
    When I click the theme switcher trigger button with data-testid "theme-switcher-trigger"
    And I click the Japanese theme option with data-testid "theme-option-japanese"
    Then the body element should have attribute data-theme equal to "japanese"

  @unit-test @priority-high
  Scenario: Theme selection persists to localStorage under key cuisine-theme
    Given I am on the home page
    And the page has fully loaded
    When I click the theme switcher trigger button with data-testid "theme-switcher-trigger"
    And I click the Mexican theme option with data-testid "theme-option-mexican"
    Then localStorage key "cuisine-theme" should contain value "mexican"

  @unit-test @priority-high
  Scenario: Saved theme is restored from localStorage on page reload
    Given I am on the home page
    And localStorage key "cuisine-theme" is set to "japanese"
    When I reload the page
    And the page has fully loaded
    Then the body element should have attribute data-theme equal to "japanese"

  @unit-test @edge-case
  Scenario: Theme change in one browser tab syncs to other tabs via storage event
    Given I am on the home page in two browser tabs
    And the page has fully loaded in both tabs
    And localStorage key "cuisine-theme" is initially empty in both tabs
    When I click the theme switcher trigger button with data-testid "theme-switcher-trigger" in tab 1
    And I click the Italian theme option with data-testid "theme-option-italian" in tab 1
    Then localStorage key "cuisine-theme" should contain value "italian"
    And tab 2 should receive a storage event for key "cuisine-theme"
    And the body element in tab 2 should have attribute data-theme equal to "italian" within 500ms

  @screenshot-test @priority-medium
  Scenario: Visual validation of theme switcher dropdown open state
    Given I am on the home page
    And the page has fully loaded
    When I click the theme switcher trigger button with data-testid "theme-switcher-trigger"
    Then the dropdown menu with data-testid "theme-switcher-menu" should be visible in the header area
    And exactly 3 theme options should be displayed: "Italian", "Japanese", and "Mexican"
    And each theme option should display a colored swatch preview next to its label

  @screenshot-test @priority-medium
  Scenario: Visual validation of Italian theme applied to page
    Given I am on the home page
    And the page has fully loaded
    When I click the theme switcher trigger button with data-testid "theme-switcher-trigger"
    And I click the Italian theme option with data-testid "theme-option-italian"
    Then the header background should display the Italian theme red accent color
    And primary buttons on the page should use the Italian green accent color
    And the body element should have attribute data-theme equal to "italian"
