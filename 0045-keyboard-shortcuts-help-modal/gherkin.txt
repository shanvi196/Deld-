Feature: Keyboard Shortcuts Help Modal
  As a user of the Deld restaurant review application
  I want to access a keyboard shortcuts help modal
  So that I can discover and learn available keyboard shortcuts for efficient navigation

  Background:
    Given the app is running at "http://localhost:3000"
    And the shortcuts help dialog is closed by default

  @unit-test @priority-high
  Scenario: Press question mark key opens shortcuts help dialog
    Given I am on the home page
    And the shortcuts help dialog is not visible
    When I press the "?" key on my keyboard
    Then the shortcuts help dialog should be visible
    And the dialog should have data-testid "shortcuts-help-dialog"
    And exactly 3 shortcut items should be displayed with data-testid "shortcut-item"

  @unit-test @priority-high
  Scenario: Help button in header opens shortcuts dialog
    Given I am on the home page
    And the shortcuts help dialog is not visible
    When I click the help button with data-testid "help-button"
    Then the shortcuts help dialog should be visible
    And the dialog title should be "Keyboard Shortcuts"
    And exactly 3 shortcut items should be displayed with data-testid "shortcut-item"

  @unit-test @priority-high
  Scenario: Shortcuts dialog displays list of available shortcuts with correct content
    Given I am on the home page
    When I press the "?" key to open the shortcuts dialog
    Then the shortcuts help dialog should be visible
    And the first shortcut item should display key "/" with description "Focus search"
    And the second shortcut item should display key "Esc" with description "Close modals"
    And the third shortcut item should display key "j/k" with description "List navigation"
    And each shortcut row should have exactly one key badge with data-testid "shortcut-key"

  @unit-test @priority-medium
  Scenario: Pressing Escape closes the shortcuts dialog
    Given I am on the home page
    And I have opened the shortcuts help dialog by pressing "?"
    And the shortcuts help dialog is visible
    When I press the "Escape" key
    Then the shortcuts help dialog should not be visible
    And the page body should not have aria-hidden="true"

  @unit-test @edge-case
  Scenario: Question mark key is ignored when typing in an input field
    Given I am on the home page
    And the search input with data-testid "search-input" is focused
    When I type "?" in the search input
    Then the shortcuts help dialog should not be visible
    And the search input should contain the text "?"

  @unit-test @edge-case
  Scenario: Dialog state persists correctly when navigating between pages
    Given I am on the home page
    When I press the "?" key to open the shortcuts dialog
    Then the shortcuts help dialog should be visible
    When I press the "Escape" key to close the dialog
    And I navigate to "/restaurants"
    Then the shortcuts help dialog should not be visible
    When I press the "?" key to open the shortcuts dialog
    Then the shortcuts help dialog should be visible
    And exactly 3 shortcut items should be displayed with data-testid "shortcut-item"

  @screenshot-test @priority-high
  Scenario: Visual validation of shortcuts help dialog opened via keyboard
    Given I am on the home page
    When I press the "?" key to open the shortcuts dialog
    Then the page should visually show a modal dialog overlay with semi-transparent backdrop
    And the dialog should be horizontally and vertically centered on the viewport
    And the dialog should display a grid layout with 2 columns: shortcut keys on left, descriptions on right
    And exactly 3 shortcuts should be visible: "/" labeled "Focus search", "Esc" labeled "Close modals", and "j/k" labeled "List navigation"
    And each shortcut key badge should have a distinct background color differentiating it from the description text

  @screenshot-test @priority-medium
  Scenario: Visual validation of help button placement and icon in header
    Given I am on the home page
    Then the help button with data-testid "help-button" should be visible in the header area
    And the help button should display a HelpCircle icon from lucide-react
    When I click the help button with data-testid "help-button"
    Then the shortcuts help dialog should appear as a centered modal with rounded corners
    And the dialog should have a title "Keyboard Shortcuts" displayed at the top in bold text
    And the backdrop behind the dialog should be visually dimmed
