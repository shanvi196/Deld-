```gherkin
Feature: Restaurant Comparison Tool
  As a user exploring multiple restaurant options
  I want to compare restaurants side-by-side
  So that I can make informed dining decisions

  Background:
    Given the app is running at "http://localhost:3000"

  @unit-test @priority-high
  Scenario: Add restaurant to comparison from search results
    Given I am on the search page at "http://localhost:3000"
    And the comparison list is empty
    When I click the comparison button on the first restaurant card with data-testid "restaurant-card-compare-button-rest_0001"
    Then the floating comparison bar should appear at the bottom with data-testid "comparison-bar"
    And the comparison bar should display "1 restaurant selected"
    And the "Compare Now" button should be visible with data-testid "comparison-bar-compare-button"

  @unit-test @priority-high
  Scenario: Add multiple restaurants to comparison
    Given I am on the search page at "http://localhost:3000"
    And the comparison list is empty
    When I click the comparison button on restaurant "rest_0001"
    And I click the comparison button on restaurant "rest_0002"
    And I click the comparison button on restaurant "rest_0003"
    Then the comparison bar should display "3 restaurants selected"
    And all three comparison button states should show as selected with data-testid pattern "restaurant-card-compare-button-rest_000[1-3]"

  @unit-test @edge-case
  Scenario: Maximum comparison limit of three restaurants
    Given I have already added 3 restaurants to comparison
    When I attempt to click the comparison button on a fourth restaurant "rest_0004"
    Then the fourth restaurant should not be added
    And the comparison bar should still display "3 restaurants selected"
    And a toast notification should appear with message "Maximum 3 restaurants can be compared"

  @unit-test @priority-high
  Scenario: Navigate to comparison view with selected restaurants
    Given I have added 2 restaurants to comparison at "http://localhost:3000"
    When I click the "Compare Now" button with data-testid "comparison-bar-compare-button"
    Then I should be redirected to "http://localhost:3000/compare"
    And the URL should be exactly "http://localhost:3000/compare"
    And a comparison table should be visible with data-testid "comparison-table"
    And the table should display exactly 2 restaurant columns

  @unit-test @edge-case
  Scenario: Remove restaurant from comparison list
    Given I am on the search page at "http://localhost:3000"
    And I have added restaurant "rest_0001" to comparison
    And the comparison bar displays "1 restaurant selected"
    When I click the comparison button on restaurant "rest_0001" again with data-testid "restaurant-card-compare-button-rest_0001"
    Then the restaurant "rest_0001" should be removed from comparison
    And the comparison bar should disappear from view
    And localStorage key "comparisonList" should be empty array

  @unit-test @priority-high
  Scenario: Persist comparison state across page navigation
    Given I am on the search page at "http://localhost:3000"
    And I have added restaurant "rest_0001" to comparison
    And the comparison bar displays "1 restaurant selected"
    When I navigate to "http://localhost:3000/restaurant/rest_0002"
    And I wait for the page to load
    Then the comparison bar should still display "1 restaurant selected"
    And localStorage key "comparisonList" should contain exactly 1 restaurant ID "rest_0001"
    And the comparison bar should be visible with data-testid "comparison-bar"

  @screenshot-test @priority-medium
  Scenario: Visual validation of comparison bar with selections
    Given I am on the search page at "http://localhost:3000"
    When I add 2 restaurants to the comparison list
    Then the floating comparison bar at the bottom should display "2 restaurants selected" text
    And the "Compare Now" button should be prominently visible
    And selected restaurant cards should show active comparison button state

  @screenshot-test @priority-high
  Scenario: Visual validation of comparison table layout
    Given I have 3 restaurants in comparison at "http://localhost:3000/compare"
    Then the comparison table should display 3 columns side-by-side
    And each column should show restaurant photo at the top
    And rows should display: name, rating with stars, price range symbols, cuisine types as pills, key features as checkmarks, and operating hours
    And each column should have a "Remove" button
    And a "Clear All" button should be visible at the top right
```
